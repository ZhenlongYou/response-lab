# ResponseLab 频响补偿算法原理说明书

## 1. 目标

在线性时不变假设下，参考链路与待补偿链路的脉冲频响分别为
\(H_r(f)\) 与 \(H_d(f)\)。目标补偿为：

\[
C(f)=\frac{H_r(f)}{H_d(f)}.
\]

## 2. 从脉冲得到频响

若采样间隔为 \(\Delta t\)，则 \(f_s=1/\Delta t\)，并使用：

\[
H(f_k)\approx\Delta t\sum_{n=0}^{N-1}h[n]e^{-j2\pi f_kn\Delta t}.
\]

两份脉冲分别计算后插值到公共物理频率轴，因此允许两者点数和采样率不同。

默认自动补偿频带先把两份幅度谱按各自峰值归一化，选择两者共同不低于 -20 dB
的最长连续区间，再从中留边界裕量得到补偿频带。当前文件组首次分析由该区间给出线性
相位拟合频带初值；同一组文件的后续自动补偿频带不会再改写该范围。若在同一窗口更换
任一拟合脉冲，尚未被用户手动编辑的自动相位频带会按新文件的采样率和 Nyquist 重新
建议；用户明确输入的范围则保留，并由新数据的物理边界重新校验。它只是幅度谱候选，
不是噪声底或相位可信度估计；输入需已去基线，用户必须检查拟合带内相位质量。推荐与
实际分析使用同一公共频率轴，不把公共 Nyquist 当成有效带宽。脉冲补零分析选择不小于
请求长度的偶数快速 FFT，因此公共轴的 Nyquist 来自真实 RFFT 端点，不会把最后一个
低频 bin 的幅度常量外推到 Nyquist。

## 3. 幅度补偿

补偿频带核心内直接使用：

\[
A(f)=\frac{|H_r(f)|}{|H_d(f)|}.
\]

原始幅度比不做正则化，完整保留在频响差异诊断中。实际应用默认把最大补偿增益限制为
20 dB；若原始需要 40 dB，诊断仍显示 40 dB，输出应用 20 dB 并给出明确提示。用户可
修改该上限，或显式关闭限制并把选择写入参数记录。数值为零、无法计算响应比的频点仍
触发明确错误，增益限制不能把零点变成可逆频点。运行结果会按目标信号实际 DFT bins
更新峰值告警，并以目标 Nyquist 判断物理边缘；raised-cosine 相位肩部分别从外侧连续
展开，避免把 ±π 的分支切换变成真实相位跳变。

所选频带内完整应用该响应比，频带外严格使用单位响应。仅幅频模式下参考响应为零时，
补偿幅度为零；待补偿响应为零时比值发散，工具会明确报错。

## 4. 相位补偿与去斜

相位差为：

\[
\Delta\phi(f)=\phi_r(f)-\phi_d(f).
\]

在用户指定的线性相位拟合频带对每个相位岛拟合
\(\Delta\phi_i(f)\approx mf+b_i\)，并报告：

\[
\hat{\tau}=\frac{m}{2\pi}.
\]

正值表示 DUT 比参考更晚，负值表示 DUT 比参考更早。“去除线性相位（保持目标时间位置）”
开关打开时，实际补偿相位使用：

\[
\phi_\mathrm{used}(f)=\Delta\phi(f)-mf.
\]

关闭时仍拟合并显示 \(\hat{\tau}\)，但使用
\(\phi_\mathrm{used}(f)=\Delta\phi(f)\)，即保留完整相位差以尝试对齐相对时间。

斜率使用频谱置信度加权的最小二乘估计。可信频带被零点分成多个相位岛时，每个岛使用
独立截距，斜率只由各岛内部的相位变化共同决定，因此相位展开造成的整数个 \(2\pi\)
岛间偏移不会污染斜率拟合。零权重频点不参加拟合，非零权重保持原始相对比例。打开
开关时实际移除的只有 \(mf\)，关闭时不移除；两种设置都不会把多个 \(b_i\) 平均成
虚假的全局截距。

界面始终显示带符号相对时延；常数相位和非线性相位仍被补偿。打开去斜时，“频率响应”
页分别扣除两份脉冲各自的线性相位，再给每个连续相位岛统一减去整数个 2π；关闭时显示
未去斜相位。“频响差异比较”页与图例声明实际开关状态。

## 5. 当前补偿响应与导出定义

补偿带内按模式构造：

\[
C(f)=
\begin{cases}
|H_r|/|H_d|, & \text{仅幅频},\\
e^{j\phi_\mathrm{used}}, & \text{仅相频},\\
(|H_r|/|H_d|)e^{j\phi_\mathrm{used}}, & \text{幅频 + 相频}.
\end{cases}
\]

带外严格为 \(1+0j\)。响应 CSV 的两路幅度保留
\(20\log_{10}|\Delta t\,\mathrm{RFFT}(h)|\) 的原始输入标度，再按对数幅度插值到公共
分析网格；只有自动推荐 -20 dB 频带时才在内部把两路频谱分别按各自峰值归一化。
原始分岛展开相位差、拟合趋势 \(mf\)、开关作用后的实际相位源和包裹后的补偿相位使用
不同字段。JSON manifest v4 记录原始频响 dB 定义与 `raw_input_scale` 标度、斜率、
带符号相对时延及符号约定。

## 6. 直接频域应用

默认把有限记录以外的样本定义为零：小记录在首尾补零；当该精确路径超过安全预算时，
大记录改用有限边界重叠分块，块接缝使用原记录真实相邻样本，只在完整记录两端补零。
显式选择 `reflect` 才恢复旧的全局镜像边界。工具通过 CZT 在目标
FFT 的实际频点直接计算两份拟合脉冲的有限记录频响，并构造补偿响应后执行：

\[
X[k]=\operatorname{rfft}\{x[n]\},\qquad
Y[k]=X[k]C(f_k),\qquad
y[n]=\operatorname{irfft}\{Y[k]\}.
\]

显示分析网格只负责绘图和诊断，不再作为实际补偿响应的插值源。接近谱零点时会用直接
多项式求值复核 CZT 结果，并用与记录长度、系数 L1 范数有关的 Horner 舍入误差界判断
数值可解析性：低于误差界的 DUT 响应会被拒绝，可解析的有限小响应先形成原始诊断，
再受用户可见的最大增益和边缘过渡设置约束。目标记录过短、补偿带内没有实际 DFT
频点时也会拒绝。实值 RFFT 的 DC/Nyquist
端点只能乘实数；若目标 Nyquist 需要超出数值误差的复相位补偿，会拒绝运行而不是静默
投影。这里没有另行拟合 FIR；精确路径的工程约束是明示的增益上限与 raised-cosine
边缘。分块路径先在 float64 目标冲激响应上审计 float32 量化误差，再把剩余 L1 预算
用于确定双边上下文，并将已计入预算的中部尾部真正置零；“量化 L1 + 截尾 L1”超过
配置上限或上下文过长都会失败关闭。精确路径反变换后取回中间原记录；分块路径只提交中央有效区。输出与输入保持
相同点数、时间轴和通道数。
在量化与截尾之前，分块路径还要求脉冲有效时间支持满足 `2D<N_FFT`，并把 N_FFT 点循环
冲激响应嵌入 2N_FFT 网格，与 2N_FFT 直接 CZT 校正比较。相对 L∞ 不收敛时拒绝；
这只是离散加密网格门禁，不是连续频率证明，也不与量化/截尾 L1 界相加伪装成总界。

大文件内存并不等于 BIN 文件字节数。单通道原始 payload 是 4 B/点；当前 BIN 幅值
保持 4 B/点 float32，时间轴仍为 8 B/点 float64。精确路径反射长度为 `E=3N-2`，
实数组和 complex128 频谱仍很大；因此超预算时自动改走 float32/complex64 分块路径。
旧实现还同时
保留全频频率轴、全频复校正、`spectrum*correction` 临时量，并让 N 点输出切片引用
整个 E 点 IFFT 缓冲。现实现只构造带内频率/校正、原地修改频谱，并把裁剪结果复制为
紧凑 N 点自有数组后释放 E 点缓冲；带内校正和 IFFT 输入频谱也在各自最后一次使用后
立即释放。100 万点、50–200 MHz 的独立进程新增峰值由约 630 MB 降为约 157.6 MB，
具体数值会随数值库和分配器变化，因此门禁仍保留充足余量。

## 7. 主要影响频段归因

“影响频段”页回答的不是“哪一段频响差异最大”，而是一个反事实问题：如果只修正某个
小频段，用户选定的 Vpp、眼高或眼宽能向参考设备恢复多少。这样，频响差曲线和最终
测量指标之间由实际波形回放连接，不用频谱峰值代替指标敏感度。

### 7.1 指标输入

#### 7.1.1 Vpp 的理想码型与脉冲窗口

Vpp 不再读取参考/DUT 两条任意采集波形，而是用两份拟合脉冲和同一个理想周期码型建立
可重放的确定性 LTI 模型。这样做的目的不是把拟合脉冲本身的峰峰值当 Vpp，而是让每个
symbol 的脉冲响应与前后 symbols 的拖尾叠加，显式观察 ISI 对最终稳态波形的影响。

用户可选择两种理想码型来源：

1. 内置 PRBS13Q Gray：固定 8191 symbols。实现冻结种子 `0000010101011`、多项式
   \(1+x+x^2+x^{12}+x^{13}\)，并把连续两位按 Gray 次序映射为四个符号码，再映射到
   归一化电平 \(\{-1,-1/3,+1/3,+1\}\)。
2. 外部单列 CSV/TXT：一行一个 symbol。GUI 固定只接受整数符号码 `0,1,2,3`，并映射
   到同一组归一化 PAM4 电平；程序不按范围猜测，也不提供无量纲幅度模式。文件在 `np.loadtxt`
   前先检查 32 MiB 硬上限与动态内存预算，冻结初始大小快照，并用有效 symbol 行数门禁
   周期 FFT；并发追加不会扩大解析输入。超限时要求提供“一列单周期 symbol，而不是采集波形”。

内置序列的 8191-symbol 与 Gray 语义可对照 Keysight 的
[PAM4 pattern 说明](https://helpfiles.keysight.com/csg/d9300a/Help/Infiniium-UG/Content/Topics/Signals/Provided_PAM4_Pattern_Files.htm)；
LFSR 种子、反馈和 golden prefix 以 IEEE 802.3 公开的
[PRBS13Q 资料](https://www.ieee802.org/3/bs/public/adhoc/elect/03Oct_16/hidaka_01_100316_elect.pdf)
为独立向量依据。这里使用它作为模型激励，不据此宣称 ResponseLab 是标准合规仪器。

设理想码型含 \(K\) 个 symbols，每 UI 采样点数为整数 \(M\)，则一个周期的样点数为：

\[
P=KM.
\]

把第 \(k\) 个理想电平 \(a_k\) 放在该 UI 的起点：

\[
s[n]=
\begin{cases}
a_k,&n=kM,\\
0,&\text{其他样点}.
\end{cases}
\]

采样率、符号率和每 UI 样点数不能混用：

\[
R_s=\frac{F_s}{M},\qquad T_{UI}=\frac{M}{F_s}.
\]

界面结果同时显示 (F_s,R_s,M,T_{UI})，用户应确认推导码率与真实码型一致。

这不是“符号之间电压为零”的 DAC 波形；它是离散卷积中的冲激列。与脉冲响应卷积后，
每个 symbol 对相邻 UI 的全部贡献才会出现在输出波形中。

参考和 DUT 各自独立选择绝对值最大峰首次出现的位置：

\[
p=\operatorname{first\ argmax}_n |h[n]|.
\]

用户输入峰前 \(L_-\) UI、峰后 \(L_+\) UI，离散窗口为：

\[
h_w[\ell]=h[p+\ell],\qquad
\ell=-L_-M,\ldots,+L_+M.
\]

窗口包含 pmax 本身和两端样点。若 \(p-L_-M<0\) 或
\(p+L_+M\ge N_\mathrm{pulse}\)，算法直接拒绝；它不裁短窗口，也不在脉冲外补零。
参考和 DUT 使用各自的 pmax，不能借用另一条脉冲的峰值位置。

这个窗口只回答“Vpp 指标模型考虑多长拖尾”。局部候选的补偿响应
\(H_r/H_d\) 始终由两份**完整拟合脉冲**计算；窗口缩短不会把补偿滤波器也同步缩短。
因此，窗口是模型假设而不是性能旋钮。应逐步增加 \(L_-\) 与 \(L_+\)，直到基线指标和
主要影响频段不再显著变化；没有做收敛检查时，结论只适用于当前截断长度。

由于参考和 DUT 周期核都把自身 pmax 定义为零延迟，完整脉冲响应比也必须使用同一相位
基准。算法先从补偿相位中减去
(t_{peak,d}-t_{peak,r})，其中 (t_{peak}=t_0+p/F_s)，再根据用户设置决定是否去除
剩余线性相位。这样 CSV 起始时间不同与数组内峰值索引不同都不会被重复补偿。

#### 7.1.2 周期稳态圆周卷积

为了避免第一段码型前面被错误假设为全零，把所有窗口 tap 按模 \(P\) 折叠到周期核：

\[
g[q]=\sum_{\ell:\ \ell\bmod P=q}h_w[\ell],
\qquad q=0,\ldots,P-1.
\]

然后计算：

\[
S[k]=\operatorname{rfft}\{s[n]\},\qquad
G[k]=\operatorname{rfft}\{g[n]\},
\]

\[
Y[k]=S[k]G[k],\qquad
y[n]=\operatorname{irfft}\{Y[k]\}.
\]

这是一个完整码型周期的稳态圆周卷积。负 lag 自动从前一周期卷回，正 lag 可以作用到
后一周期；所以周期边界上的 symbol 同样看到前后拖尾。若窗口长于一个周期，同一个模
位置可能被多个 tap 命中，必须求和而不是覆盖。

#### 7.1.3 LFP 峰峰值

LFP 方法对参考、DUT 与每个候选的完整稳态周期计算：

\[
V_{pp,\mathrm{LFP}}=\max_{0\le n<P}y[n]-\min_{0\le n<P}y[n].
\]

当码型 (a[k]) 是无量纲符号系数、拟合脉冲 (h[n]) 表示每单位符号响应且单位为 V 时，
卷积波形和结果单位都是 V。它是这个确定性周期上的精确极差，不是
\(Q_{99.9\%}-Q_{0.1\%}\)、分块中位数或有限随机采集的“稳健 Vpp”。因此每个候选必须
至少恢复一次完整周期时域波形，才能知道真正的最大值与最小值。

#### 7.1.4 复频谱 AC RMS 误差

频域方法的目标不是计算候选波形本身有多少 RMS 能量，而是计算候选与参考之间还剩多少
**复数频谱误差**。设候选稳态频谱为 \(Y_b[k]\)，参考为 \(Y_r[k]\)：

\[
D[k]=Y_b[k]-Y_r[k],\qquad D[0]=0.
\]

复数相减保留幅度和相位误差；若先计算 \(|Y_b|-|Y_r|\)，相位相反但幅度相同的反例会
被错误判为零。令周期长度为 \(P\)，SciPy 未归一化前向 FFT 的 Parseval 关系给出偶数
长度时：

\[
E_{\mathrm{RMS}}=
\frac{1}{P}
\sqrt{
2\sum_{k=1}^{P/2-1}|D[k]|^2+|D[P/2]|^2
}.
\]

内部频点具有负频共轭伙伴，所以乘 2；Nyquist 点只有一个实自由度，只计一次；DC 已
排除。奇数 \(P\) 没有独立 Nyquist 点，所有非 DC rFFT bins 都乘 2。若波形单位是 V，
结果单位为 Vrms。参考相对于自身的指标定义为 \(0\ \mathrm{Vrms}\)。

该方法不是 LFP，也不存在无需证据的“RMS 转 Vpp”系数。批量扫描时直接在频域计算，
不为每个候选执行 IFFT；只有用户点选候选、页面需要展示波形时才恢复一次周期时域结果。

一个可手算例子：令 \(M=2\)，理想周期电平为 \([-1,+1]\)，所以
\(s=[-1,0,+1,0]\)。参考脉冲只有主 tap 1；DUT 另有一个延后 1 样点、幅度 0.25 的 tap。
周期输出分别为：

\[
y_r=[-1,0,+1,0],\qquad
y_d=[-1,-0.25,+1,+0.25].
\]

两者 LFP 都是 \(2\ \mathrm{V}\)，所以 LFP 看不到这个特定拖尾；但误差波形
\([0,-0.25,0,+0.25]\) 的 AC RMS 为：

\[
\sqrt{(0.25^2+0.25^2)/4}=0.1768\ \mathrm{Vrms}.
\]

这说明两种方法回答不同问题：LFP 关心最大全摆幅，频域误差关心整个周期与参考的均方
偏差，二者不能相互替代。

一个边界反例：若 \(M=8\)、pmax 索引为 32，而用户要求峰前保留 8 UI，则窗口起点为
\(32-8\times8=-32\)。程序必须在构造 FFT 前拒绝，而不是把缺少的 32 点补成零；后者会
伪造一个看似合法、实际改变了信道拖尾的模型。

#### 7.1.5 眼高与眼宽

眼高和眼宽只使用两份等长、等采样率的拟合脉冲。用户只输入每 UI 样点数 `M`；算法从
完整脉冲样点数自动计算 `Np`，并严格校验：

\[
N_p=\frac{N_\mathrm{pulse}}{M}\in\mathbb{Z},\qquad
R_\mathrm{symbol}=f_s/M.
\]

两份脉冲样点数必须相同且都能被 `M` 整除。自动得到的 \(N_p\ge 2\)，同时
\(M\ge 3\)；\(N_p=1\) 无法保留足够稳态边界，\(M=2\) 时理想眼的边界线段会落入
显示窗两端的 1% 保护区，无法提供可靠眼宽。`Np` 仍作为内部卷积与稳态裁剪长度使用，
但不再是独立界面输入。
界面默认 `M=32` 并可直接开始分析；用户修改后新值立即生效。更换参考或 DUT 拟合脉冲
不会额外要求确认，结果摘要仍显示推导出的 Fs、Rs、M 与 UI，供用户核对物理码率。

固定种子生成 NRZ 电平 \(\{-1,+1\}\) 或归一化 PAM4 电平
\(\{-1,-\tfrac13,+\tfrac13,+1\}\)。先在每个符号位置放置一个冲激
\(u[kM]=a[k]\)，其余样点为零，再与实际拟合脉冲做完整卷积：

\[
y[n]=\sum_k a[k]h[n-kM]
\]

构造确定性波形。主抽头按拟合脉冲的最大绝对峰值确定，不需要 Nb：

\[
i_0=\arg\max_n |h[n]|.
\]

参考和 DUT 补偿前分别冻结一次主抽头索引。设冻结索引为 \(i_0\)，第 \(k\) 个符号的眼图轨迹为：

\[
e_k[q]=y[kM+i_0+q],\qquad q=-M,\ldots,+M.
\]

因此每条轨迹都是 \(-1\ \mathrm{UI}\) 到 \(+1\ \mathrm{UI}\)、共 \(2M+1\) 点；距离
卷积两端不足一个脉冲支撑的符号不参与。界面先按 DUT 补偿前的发送电平和中心幅度
分位从完整记录中确定性选取最多 600 个符号位置，参考/补偿前/补偿后复用同一组位置，
再以细线半透明叠加；中心线固定在 0 UI。该选择覆盖头尾与
经验尾部，不再只取记录开头，也不把一个 UI 相位样点统计成密度热图。

参考脉冲主光标仅归一化一次，DUT 和所有补偿候选都使用相同幅值尺度。参考和
DUT 补偿前分别冻结自己的主光标；DUT 的所有候选继续使用补偿前的冻结索引，不能
通过重新归一化或移动主光标获得虚假改善。这个幅值是“相对参考主光标”的归一化量，
没有发射电平标定时不写成绝对电压 V。轨迹生成完成后，测量内核直接使用已知发送
符号标签，不再进行电平聚类、CDR 或最佳采样中心搜索。设中心符号等于电平 \(L_j\) 的
全部稳态轨迹集合为 \(E_j(\tau)\)，默认一侧经验概率为 \(p=0.01\)。眼高固定在主抽头
0 UI 读取相邻轨道的内侧经验边界：

\[
U_j=Q_{1-p}\!\left(E_j(0)\right),\qquad
D_{j+1}=Q_p\!\left(E_{j+1}(0)\right),
\]

\[
H_j=D_{j+1}-U_j.
\]

PAM4 使用三只眼中的最小眼高。负值表示两轨的经验边界已经重叠；内部保留负值，否则
仍然闭眼但正在改善的候选会全部被压成零。这里的 \(p=1\%\) 只是固定、有限轨迹数据库
的一侧经验分位数，不是 BER 或 SER 外推；程序化调用可设 \(p=0\) 以使用本次固定轨迹
数据库的确定性最坏边界。

眼宽复用本地眼图库的最大水平切片定义。先计算各发送轨在 0 UI 的中位数 \(m_j\)，再在
相邻 \(m_j,m_{j+1}\) 间从 5% 到 95% 均匀扫描 41 个固定判决电压 \(v_s\)。对每条轨迹
分别在 0 UI 左、右搜索 \(e_k(\tau)=v_s\)；同一侧有多个 crossing 时，只保留最靠近
0 UI 的一个。相邻样点 \((\tau_i,e_i)\)、\((\tau_{i+1},e_{i+1})\) 之间使用线性插值：

\[
\tau_\mathrm{cross}=\tau_i+
\frac{v_s-e_i}{e_{i+1}-e_i}(\tau_{i+1}-\tau_i).
\]

若某个样点恰好等于切片电压（包括相切），该样点本身也算 crossing；这样不会因 IEEE
浮点正零、负零的符号位差异产生阈值极性偏置。

设所有轨迹的左、右内侧 crossing 分别为 \(T_L(v_s)\)、\(T_R(v_s)\)，该水平切片的
经验宽度为：

\[
W_j(v_s)=Q_p\!\left(T_R(v_s)\right)
-Q_{1-p}\!\left(T_L(v_s)\right),\qquad
W_j=\max\!\left(0,\max_s W_j(v_s)\right).
\]

显示窗两端各裁掉 1%，避免折叠边界的重复端点冒充中心眼 crossing；每侧至少需要
\(\max(5,\lceil1/p\rceil,\lceil0.01N_\mathrm{trace}\rceil)\) 个事件；默认
\(p=0.01\) 因而至少为 100。没有任何受支持切片时返回“不可测”
而不是数值零；PAM4 任一眼不可测时不进入数值排名，否则使用三只眼中的最小眼宽。
固定符号数由内部自动选择，同一序列贯穿参考、DUT 和全部候选；全部稳态轨迹参与指标，
600 条只限制绘图。只比较眼高时无论批量扫描还是点选眼图都跳过无关的 41 条水平切片；
眼宽排名与点选眼宽仍使用完整测量口径。

### 7.2 幅度、相位与幅相反事实

两份脉冲在目标记录自己的 DFT 频点上直接求有限记录频响，并缓存：

\[
L(f)=\ln\frac{|H_r(f)|}{|H_d(f)|},\qquad
\Phi(f)=\operatorname{unwrap}\angle\frac{H_r(f)}{H_d(f)}.
\]

沿用的“去除线性相位”开关打开时，整体线性相位趋势先从 \(\Phi(f)\) 中去除，避免把
示波器间的时间原点或共同延迟误判成局部相位损伤；关闭时保留完整连续相位差。对候选
满权核心及其余弦肩部的权重 \(w_b(f)\)，三种干预分别为：

\[
C_A(f)=e^{w_b(f)L(f)},\quad
C_P(f)=e^{jw_b(f)\Phi(f)},\quad
C_{AP}(f)=e^{w_b(f)L(f)+jw_b(f)\Phi(f)}.
\]

幅度在对数域插值，因此半权重对应几何均值，而不是错误的线性电压插值。相位必须先
展开成连续分支再乘平滑权重，不能直接对包裹在 \(\pm\pi\) 的角度加窗。眼指标与 LFP
候选在同一目标基础频谱上执行 IFFT 后重算指标；频域 RMS 误差直接在复频谱上用 Parseval
重算，不执行逐候选 IFFT。三种路径都只计算用户当前选择的唯一指标。

幅度和相位使用不同的可解析条件。若 \(H_d(f)\neq0\) 而 \(H_r(f)=0\)，则
\(L(f)=-\infty\)：对任何正权重，纯幅度补偿的数学极限都是
\(e^{w_bL}=0\)，所以该点可以处理，并不需要用一个任意小的正数代替零。可是零复响应
没有可辨识相位，因而相位和幅相候选只要实际肩部或核心覆盖该点，就保守标为不可解析。
若 \(H_d(f)=0\)，分母不可逆，幅度、相位和幅相都不跨零点插值或猜测。

若参考指标为 \(m_r\)、补偿前 DUT 指标为 \(m_d\)、候选补偿后为 \(m_b\)，改善分数为：

\[
S_b=|m_d-m_r|-|m_b-m_r|.
\]

正值表示更接近参考，负值如实表示该候选使结果变差。全扫描频带的幅度、相位和幅相
补偿仍会计算，用于显示“当前线性频响模型是否整体闭环”的诊断；它们不再是局部候选的硬门禁。
只要原始参考与 DUT 差距超过浮点容差，所有局部带宽仍直接回放；若没有有效的正改善候选，
才返回“无推荐”，不从数值噪声中强行挑选一个频段。

推荐分两步完成。第一步不使用 1% 规则，直接在有效、正改善的局部候选中，
按原始 \(S_b\) 锁定全局最佳频段。第二步只在这个已锁定频段内检查模式：若原始最佳为
“幅相”，而同频段的幅度或相位改善与它的差不超过简化阈值，则选择改善更大的单模式
标签；该阈值取原始指标差距的 1% 与浮点容差中的较大值。否则保留“幅相”。因此 1%
规则只回答“同一频段是否确实需要两个因素”，绝不会为了简化标签而跳到另一个频段。

### 7.3 可设置频段宽度与物理分辨率

候选文字中的起止频率表示**满权核心**，不是整个非零窗。设核心为
\([f_l,f_h]\)，核心宽度 \(W=f_h-f_l\)，每侧肩宽 \(s=0.5W\)，则实际权重为：

\[
w_b(f)=
\begin{cases}
0, & f<f_l-s,\\
\frac{1}{2}\!\left[1-\cos\!\left(\pi\frac{f-f_l+s}{s}\right)\right],
& f_l-s\le f<f_l,\\
1, & f_l\le f\le f_h,\\
\frac{1}{2}\!\left[1+\cos\!\left(\pi\frac{f-f_h}{s}\right)\right],
& f_h<f\le f_h+s,\\
0, & f>f_h+s.
\end{cases}
\]

界面允许设置 \(W\)，默认 \(100\ \mathrm{MHz}\)。默认左右肩部各为 \(50\ \mathrm{MHz}\)，
整个非零支撑宽度为 200 MHz。核心两端都取权重 1，相邻核心的公共边界也为满权，不会像端点
为零的 Tukey 窗那样留下低敏感度扫描缝。肩部在扫描域边缘裁断，域外始终为单位补偿。

规则核心从扫描下限开始，每 \(W\) 前进一次。若最后一个规则核心的高端没有恰好到达
`scan_high`，算法会再追加一个宽度不变的核心 \([\texttt{scan\_high}-W,
\texttt{scan\_high}]\)。它可以与前一个核心重叠，但不能缩窄，并确保非整数尾段也至少
落入一个满权核心。

有限拟合脉冲的独立物理分辨率按 \(f_s/N_\mathrm{pulse}=1/T_\mathrm{record}\) 估计。Vpp 模式还要纳入
周期码型模型的 \(f_s/(K M)\)，实际核心宽度使用这些分辨率中的
最差者。若它大于用户所设 \(W\)，候选中心仍按 \(W\) 规则步进以显示趋势，但满权核心宽度
向上扩大到 \(W\) 的整数倍，肩宽仍为实际核心的一半，并给出告警；镜像延拓或零填充
产生的更密 DFT 点不会被宣称为更高物理定位能力。

### 7.4 无效证据、工作量与取消

一个候选只要其正权重核心或肩部覆盖了当前模式无法解析的频点，就保留为无效候选。
结果曲线用 `NaN` 和独立有效掩码表达这种状态，界面画出断点；零只表示“该候选已经
成功计算且改善恰好为零”，不能同时充当失败占位值。

后台在建立大型频谱前，使用与正式扫描相同的候选生成器估算工作量。眼图模式的估算
同时纳入 `symbol_count × M` 卷积波形和轨迹缓冲；眼宽还按每只眼 41 条水平切片、
左右 crossing 扫描和总评估次数计费。Vpp 估算纳入 `K × M` 的激励、
圆周核、复频谱和稳态波形，不只计拟合脉冲 FFT。独立子进程对内置 PRBS13Q、M=32、
RMS 扫描测得新增峰值约 448 B/周期点，因此门禁用 576 B/点；LFP 还保留完整周期
IFFT 与波形副本，使用 640 B/点。局部候选频带并不缩短全周期频谱数组，不能按带宽
比例下调这两个系数。候选核心超过 2000 个，或保守预计峰值内存超过共享动态预算时，
任务在分配前拒绝。动态预算与主补偿和加载器相同，取 8 GiB、当前可用内存 50% 与
保留 512 MiB 系统余量三者最小值；目标样点数乘总评估
次数超过 5000 万时，界面先提示这是长任务，但不静默降采样或改变频段定义。

取消是安全的阶段边界取消，而不是从任意机器指令中杀死数值库。线程会在源文件分块
哈希、CSV 行扫描与解析、BIN 头部扫描和 payload 映射边界，以及工作量估算后、工作区
准备后、每个候选评估之间、点选回放的 FFT/IFFT 前后检查取消请求。若单次 FFT、IFFT
或卷积已经进入底层数值调用，它会先完成该步，再丢弃过期结果；因此“可取消”不等于
单次变换能够即时抢占。

整包导出的响应诊断 CSV 以固定行块构造和写出，避免一次性复制十列全量矩阵，并在块间
响应取消。若三份最终输出已完整提交但临时文件或旧备份清理不完整，GUI 会显示警告与
人工检查路径；这类结果不误报为提交失败，也不静默当作无条件成功。

### 7.5 能力边界

眼高和眼宽是固定理想符号序列下的 LTI/确定性 ISI 近似，用来对频段进行相对排序；它
不包含 CDR、随机抖动、噪声、BER 外推、协议编码或示波器私有眼图算法。Vpp 同样来自
“拟合脉冲窗口 × 理想周期码型”的确定性模型，而不是示波器原始采集统计；窗口外拖尾、
噪声、抖动、非线性和码型相关模拟前端行为均不在模型内。结果表示“在当前线性频响模型
和当前码型/窗口下，单段补偿足以改善指标的大致频段”，不等同于唯一物理根因、真实链路
峰峰值或标准合规测量结论。

## 8. Keysight Infiniium CSV 的识别与采样率合同

### 8.1 先识别格式，再读取数值

`.csv` 只说明文本容器，不说明里面一定是时域波形。Keysight 同一扩展名还会保存眼图
命中矩阵、协议解码与测量结果。ResponseLab 因此不在文件中搜索一个看起来像 `Data`
的字符串，而只检查首个有效记录：

- `File Format, WaveformXYValues`：进入 Infiniium 自描述 XY 波形合同；
- `Time (s),<source> (V)`：进入 Keysight 官方 Python 采集示例合同；
- 首行直接是数值：保留原有无表头 `time,value` 兼容入口；
- `File Format, DatabaseCsv` 等其他家族：明确拒绝。

`WaveformXYValues` v1/v2 都要求唯一的 `Format Version`、`Points`、
`X Units, Second`、`Y Units, Volt` 和 `Data`。版本 2 在 `Data` 后增加 X/Y 精度行，例如
`double, float`；版本 1 没有该行，按 double/double 解释。未知附加元数据可以存在，
但必需字段缺失、重复、单位错误或实际数据行数与 `Points` 不同都会拒绝。

### 8.2 为什么表头里仍没有直接使用的 Fs

当前官方 XY 示例逐点保存时间值，并没有独立 `XIncrement` 字段。加载器从完整时间列
计算：

\[
\Delta t=\operatorname{median}(t[n+1]-t[n]),\qquad f_s=\frac{1}{\Delta t}.
\]

例如相邻点中位间隔为 $25\ \mathrm{ps}$，则 $f_s=40\ \mathrm{GSa/s}$。同时必须
确认时间严格递增、局部间隔足够一致，且相对理想等间隔网格的累计残差在 Nyquist 处
不超过 1°。这一步不能省略：Keysight 官方明确说明 XY 格式可表示不等间隔采样，只有
保存时选择 `Linearly Interpolate` 才强制等间隔。`Interpolation Factor` 是描述字段，
不是采样率。

自描述或官方 Python 表头已经固定 X 为秒、Y 为伏特，调用方不能再用手工单位或列映射
覆盖。无表头文件没有这些身份信息，GUI 只按明确兼容合同解释为第 1 列秒、第 2 列伏特，
并不会把它标记成已验证的 Keysight 自描述文件。

CSV 的头扫描设置 256 行、1 MiB 总表头和 64 KiB 单行上限。加载器在同一打开文件描述符
上先做内容哈希、物理行统计和动态内存预算，再让 `np.loadtxt` 建表；解析后重新核对内容
快照和目录项身份。预算包含文本解码、数值转换、选中列和可选重采样工作区，大文件会在
分配数值表前停止，而不是先把文件塞满内存再报错。GUI 的自描述、显式表头和通用无表头
路径都完整验证恰好两列，因此第一个或中间任一数据行出现第 3 列都会失败；只有底层
程序化 API 未启用严格列数合同时，才可按显式列映射用 `usecols` 读取宽表。

当前自动化验收使用按官方页面独立构造的 v1/v2、CRLF、官方 Python 表头和无表头夹具。
尚未获得可再分发的实机 CSV，因此结果只能表述为“符合已公开格式合同”，不能表述为
“所有 Keysight CSV 已实机验证”。旧式 `Revision` 多源/分段格式待取得真实样例后再
建立独立 reader。

官方依据：

- [Keysight Waveform XY CSV](https://helpfiles.keysight.com/csg/d9300a/Help/Infiniium-UG/Content/Topics/Files/waveform_xy_files.htm)
- [Keysight Waveform HEADer](https://helpfiles.keysight.com/csg/d9300a/Help/Infiniium-PG/Content/Topics/Commands/DISK/WAVeform_HEADer.htm)
- [Keysight Python 浮点波形示例](https://helpfiles.keysight.com/csg/d9300a/Help/Infiniium-PG/Content/Topics/Python/Scripts/waveform-data-float-format.htm)

## 9. Keysight Infiniium BIN 的时间轴合同

### 9.1 为什么不能把 `.bin` 当成裸 float32

扩展名只说明文件名，不说明字节布局。裸 `float32` 没有自描述采样率、时间原点、单位、
通道或数据类型；让用户手填这些字段会产生大量“能读出数，却读错物理意义”的假成功。
ResponseLab 因此只接受 Keysight Infiniium 官方说明的 `AG10` 容器子集，并先验证结构，
再接触 waveform payload。

文件级头包含 `AG` Cookie、版本、文件长度和 waveform 数；每个 waveform header 包含
`Points`、`X Increment`、`X Origin`、X/Y 单位等；每个 data header 再声明 buffer 类型、
每点字节数与 payload 长度。加载器使用显式 little-endian 字段布局，并检查所有 header
size、payload 边界和最终 EOF。2026 版 Infiniium 可能把 File Size 写成 0，因此 0 只表示
“以实际 EOF 为边界”；非零声明仍必须与实际文件长度完全相等。

### 9.2 自动采样率与时间原点

当 X 单位为 Second、`X Increment` 是正有限秒数时：

\[
f_s=\frac{1}{\Delta t},\qquad
t[n]=t_0+n\Delta t,
\]

其中 \(\Delta t=\text{X Increment}\)，\(t_0=\text{X Origin}\)。例如
`X Increment = 25 ps` 时，\(f_s=40\ \mathrm{GSa/s}\)；若
`X Origin = -1 ns`，第 0 点的真实时间就是 \(-1\ \mathrm{ns}\)，不能重置为 0。
Y 单位必须为 Volt，避免把 ADC counts 或其他量纲直接标成电压。

当前 GUI 要求文件恰好一个 waveform。底层解析器虽可由程序显式给索引，但 UI 不在多
waveform 文件中自动挑选“第一个看起来能读”的记录。可加载 waveform 类型限于 Normal
与 Average，且必须恰好有一个与 `Points` 完全一致的 normal little-endian float32
buffer。Peak Detect 的双 buffer、数字/逻辑/直方图/复数数据、未知版本、非秒 X 轴、
非伏特 Y 轴、截断、尾随未知字节和普通裸 BIN 都会在进入补偿前拒绝。
GUI 路径在 File Header 读到 waveform 数量不为 1 时立即停止，不先构造各 waveform 的
Python 描述符。通用 inspect 最多接受 4096 个 waveform 描述符和 4096 个全文件 buffer
描述符；这两个文件级上限独立于 payload 内存预算，专门关闭小头部驱动元数据放大。

大型 BIN 先只扫描头部，并按 `Points` 以 `24 B/点 + 16 MiB` 预估解码工作集；超过
共享动态预算或显式解码上限时，在映射 payload 前停止。GUI 还会用同一已打开文件的
头部几何，在 payload 哈希和映射前执行完整补偿形状规划，并为随后常驻的 float64
时间轴与 float32 幅值预留 `12 B/点`。受支持的 payload 使用只读内存映射，避免仅为
“看一眼头部”就复制整份
float32 数据。头部已经严格定义 `X Origin + index × X Increment` 后，加载器只构造
一次 float64 时间轴和一次原生 float32 幅值副本；实际间隔按 131072 点分块验证，
不再生成全长 diff、median 与第二条理想时间轴。100 万点两次独立进程实测加载新增
峰值约 19.9–20.8 MiB（macOS arm64）。后续 TimeSeries、输出和 FFT 仍需要工作区，
所以内存映射本身
不等于任意大文件都可运行。主“数据补偿”不再给 BIN 单设固定点数硬上限：CSV/BIN
形成同一 TimeSeries 后，`run_compensation` 在响应分析、CZT 和目标 FFT 前执行共享
预检。小记录先估算 `E=3N-2` 精确路径，超预算时改估完整 float32 输出、块 FFT、
float64 目标/float32 应用冲激响应、量化与上下文审计数组、反射索引和脉冲 CZT；
预算取 8 GiB、当前可用内存 50% 与保留 512 MiB 系统余量三者最小值，探测失败时
使用 768 MiB 保守回退。

### 9.3 导出与不能证明的兼容性

BIN 导出写一个 Normal waveform：`AG10`、Second/Volt、由时间轴得到的 X Increment、
保留输入第一个时间点的 X Origin，以及 little-endian float32 payload。写入按块量化并
原子替换目标文件，NaN、Inf、float32 溢出、非均匀时间轴和多通道都会拒绝。

这能证明“本工具写出的受支持 AG10 子集可以由本工具按相同合同重读”，不能证明：

- 能读取所有以 `.bin` 结尾的文件；
- 能读取 Keysight 其他产品线的 IQ、频域、数字或私有 BIN；
- 能保留输入文件的其他 waveform、复杂 buffer、分段采集与未建模元数据；
- 能无损写回第三方或厂商私有容器。

遇到这些格式应取得对应产品与版本的官方格式说明、真实脱敏样例和独立读回工具，再建立
明确 adapter；不得恢复“高级裸 BIN”让用户靠试 dtype、偏移和 Fs 猜出一条像波形的曲线。
