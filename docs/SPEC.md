# ResponseLab v0.1 实现规格

> 状态：当前代码的真实行为，更新于 2026-07-17。

## 1. 产品目标

ResponseLab 是一个 macOS 桌面工具，用于比较参考拟合脉冲与待补偿拟合脉冲的复频响，
按 `H_ref / H_dut` 构造补偿响应，并通过 `FFT → 频域相乘 → IFFT` 应用到 CSV 或原始
BIN 信号。

## 2. 输入

- 两份拟合脉冲使用无表头 CSV，第 1 列时间固定为秒，第 2 列为幅值；采样率分别从时间
  间隔得到。
- 待补偿 CSV 使用同样格式。
- 待补偿 BIN 必须手动输入采样率，并可设置数据类型、字节序、文件头偏移、通道布局、
  幅值缩放和偏置。
- 时间轴必须严格递增且等间隔，最少 8 点。

## 3. 频响分析

每份脉冲分别计算 `dt · rfft(h[n])`，然后插值到从 0 到两者较小 Nyquist 的公共物理
频率轴。幅度差为：

```text
ΔA_dB(f) = 20 log10(|H_ref(f)| / |H_dut(f)|)
```

相位只在连续、数值可解析的频段内展开。数值零点不会被当成有效响应比。

## 4. 补偿

- 支持仅幅频、仅相频、幅频和相频三种模式。
- 用户设置补偿起点与终点；补偿频带外为单位响应。
- 所选频带内完整应用分析差异，频带外严格使用单位响应。
- 频带核心内的幅度比不做正则化、最大增益或最大衰减裁剪。
- 若所选频带包含无法数值解析的响应比，分析会拒绝并提示缩小或移动频带。

## 5. 相位去斜

含相位的模式在用户选择的观察频带内拟合相位差公共斜率：

```text
estimated_dut_delay = slope / (2π)
phase_used(f) = Δφ(f) - slope · f
```

各连续可信相位岛使用独立干扰截距，按归一化频谱幅度平方加权，只汇总岛内相位变化来
估计公共斜率。零权重频点不参与拟合。结果中的 `phase_trend_rad` 表示实际移除的
`slope · f`，而不是把各岛截距平均成一条没有物理意义的全局直线。

相对时延只显示，不写入补偿相位；常数相位和非线性相位差保留。

## 6. 目标数据处理

目标信号先自动做首尾镜像延拓，补偿响应再按对数幅度与展开相位插值到延拓记录的
DFT 频点：

```text
Y[k] = rfft(x[n]) · C(f_k)
y[n] = irfft(Y[k])
```

反变换后取回中间的原记录，避免循环回卷；输出与输入保持相同点数、时间轴和通道数。

## 7. UI

- 标题说明固定为“频响分析与补偿”。
- 深色三栏工作台：左侧输入，中间五个绘图页，右侧参数。
- 参数只呈现输入解析所需字段、补偿模式、补偿频带和相位去斜观察频带。
- “拟合脉冲比较”只要求两份脉冲；“数据补偿”才要求第三份目标信号并启用导出。
- 绘图工具栏显式提供框选放大、拖动和恢复推荐范围，滚轮缩放始终可用。
- 五个绘图页为：拟合脉冲、频率响应、频响差异比较、频响补偿、输出预览。
- 只做脉冲比较时禁用“输出预览”，避免把候选补偿响应误解为已经应用的结果。
- 任意输入或参数变化会使当前预览失效并禁用导出。

## 8. 导出

一次导出生成主输出、响应 CSV 和 JSON manifest。manifest 记录输入来源、有效设置、估计
时延、直接频域应用信息、输出统计和哈希。源文件在导出前后与分析时快照核对，三个输出
作为可回滚批次提交。
