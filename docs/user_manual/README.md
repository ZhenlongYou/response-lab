# ResponseLab 中文使用说明书

本目录保存与当前 ResponseLab 图形界面对应的详细中文使用说明书。

## 使用方法

1. 下载本目录全部文件，保留现有目录结构。
2. 双击 `ResponseLab_频响补偿工具_使用说明书.html`。
3. 使用浏览器打开后，可通过左侧目录或顶部搜索框查找功能。

不要只下载 HTML 文件；六个页签的界面截图位于 `ResponseLab_使用说明书_assets/`，缺少该目录时图片不会显示。

## 内容范围

- 三类输入数据及格式要求；
- 六个页签的界面与结果解读；
- 每个按钮、参数和不可用状态；
- 补偿、影响频段分析与结果导出流程；
- 常见问题、结果边界和故障排查。

说明书依据仓库提交 `a78e1ecfed5f3643f9e5ff5032cc282567716d2d` 的界面和功能编写。配套验收记录见 `ResponseLab_使用说明书_验收记录.json`。
