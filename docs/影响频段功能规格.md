# 影响频段功能规格

## 1. 目标

在现有 ResponseLab 中新增“影响频段”页签，用可解释的反事实扫描自动定位主要影响
Vpp、眼高或眼宽的大致频段，并区分幅度、相位与幅相联合影响。该能力属于
内部工程近似，不复制示波器私有测量算法，也不宣称为标准合规眼图。

## 2. 用户已确认的交互

- 新页签名称：`影响频段`。
- 指标下拉框：`Vpp`、`眼高`、`眼宽`；每次只按一个指标排名。
- 调制下拉框：`NRZ`、`PAM4`；仅眼高/眼宽模式需要。
- 频段宽度：三种指标共用，界面单位 MHz，默认 100 MHz；同时决定满权核心宽度和规则
  候选中心步进。
- 拟合脉冲参数：用户只输入每 UI 采样点数 `M`；采样率从 CSV 时间轴计算，`Np` 自动按
  `samples / M` 推导，并校验两份脉冲等长、`samples % M == 0`、`Np >= 2`、`M >= 3`。
- 页面标签保持简洁，不在下拉框、图标题或结果卡重复显示“虚拟”、“ISI”、
  “工程近似”等限定词；边界只在帮助、工具提示和报告中说明一次。
- 选择眼高或眼宽时，页面绘制`参考`、`补偿前`、`补偿后`眼图，并共用坐标、
  符号序列和判决规则。每条轨迹围绕冻结主光标显示 `-1 UI ~ +1 UI`，
  不使用密度热图替代轨迹叠加。

## 3. 输入与物理量

### 3.1 共通输入

- 参考拟合脉冲 `h_ref(t)` 和 DUT 拟合脉冲 `h_dut(t)`：必须等长、等采样率、时间轴
  等间隔。
- 扫描起止频率沿用右侧补偿频带，并限制在拟合脉冲与指标数据共同 Nyquist
  以内。
- 候选标签表示用户所设的满权核心，默认 100 MHz，规则核心按同一宽度步进；每侧另接
  实际核心一半宽度的半余弦肩部，避免相邻频段在边界漏扫。若有限拟合脉冲不支持用户
  所设物理分辨率，核心宽度向上扩为所设宽度的整数倍并给出明确警告，零填充后的频点间隔不充当独立
  物理分辨率。Vpp 还要纳入实际被补偿 DUT 原始记录的 `fs/N`。

### 3.2 Vpp

- 使用参考原始数据与 DUT 原始数据；两者允许不同长度和不同采样率。
- 各自根据时间轴建立频率网格，不为了标量指标强制重采样或逐点对齐。
- 默认稳健 Vpp 为 `Q99.9% - Q0.1%`；分块时长取两份记录中较短者的有效时长，
  较长记录按该时长分块后取各块 Vpp 中位数。同时保留极值 Vpp 诊断，频段排名
  只使用稳健值。
- CSV 各自从时间轴推导采样率。两份 BIN 共用右栏同一组格式和采样率配置；两条 BIN
  若实际采样率不同，应使用带各自时间轴的 CSV，不允许把一个公共采样率冒充两侧真值。

### 3.3 眼高与眼宽

- 不读取原始数据，而是由拟合脉冲与固定、可重放的 NRZ/PAM4 符号序列生成数据波形：

  `y[n] = sum_k a[k] * h[n - k*M]`

- NRZ 电平为 `{-1, +1}`，PAM4 电平为 `{-1, -1/3, +1/3, +1}`，序列种子和长度
  固定可重放。
- 符号写入间隔 `M` 点的冲激列，再与拟合脉冲做完整卷积。第 `k` 条轨迹以
  `k*M + main_cursor_index` 为中心，截取 `-M ... +M`，即 `-1 UI ~ +1 UI`、
  `2M+1` 点；避开卷积首尾边界，界面最多叠加 600 条半透明细轨迹。
- 主抽头索引按 `argmax(abs(h))` 取得；参考和 DUT 补偿前分别冻结一次，不需要 Nb。
- 默认眼高在固定 0 UI 按已知发送电平分组，取高一轨道的 `Q1%` 减低一轨道的 `Q99%`；
  PAM4 分别计算三只眼，排名使用最小眼。负值表示两条轨道已经重叠，内部保留负值以
  区分仍闭眼但正在改善的候选。这里的 1% 是固定轨迹数据库的一侧经验分位数，不是
  BER/SER 外推。
- 眼宽复用本地眼图库的水平切片定义：在每对相邻轨道中心中位数的 5%～95% 区间扫描
  41 个固定判决电压；每条轨迹每侧只保留最靠近 0 UI 的 crossing，并在相邻样点间线性
  插值；样点恰好等于切片电压（含相切）也记为命中。左边界取 `Q99%`、右边界取
  `Q1%`，选择 41 个切片中的最大宽度并限制为
  非负 UI 值，不额外截断到 `1 UI`。每侧至少需要 `max(5, ceil(1%*轨迹数))` 个
  crossing；PAM4 排名使用
  三只眼中的最小宽度。任一眼缺少足够左右 crossing 时标为不可测，不能用 `0 UI`
  冒充已经测得的闭眼。
- 参考主光标只归一化一次，DUT 与全部候选使用同一幅值尺度。参考和 DUT
  补偿前分别冻结主光标索引；DUT 候选沿用补偿前索引，不为每个频段重新归一化或
  重新定位。眼高因此是相对参考主光标的归一化幅值，不标成绝对电压 V。

## 4. 频段干预与排名

- 相对响应为 `R(f) = H_ref(f) / H_dut(f)`。
- 开启去斜时，线性相位趋势作为整体时延单独移除，局部频段只扫描残余相位；关闭时
  保留完整连续相位差。
- 每个候选频段分别运行`幅度`、`相位`、`幅相`，不用频响差曲线峰值代替指标回放。
- 候选起止频率是满权核心。默认核心宽 100 MHz，也可由用户设置；两侧分别用实际核心
  一半宽度的半余弦从 0 平滑过渡到 1；核心两端均为满权，因此相邻核心的公共边界不会出现 Tukey 零
  端点缝。肩部裁到扫描范围，域外仍为单位补偿。
- 满权核心不小于拟合脉冲的 `1 / T_record` 物理尺度，并向上取用户所设宽度的整数倍；
  `alpha = 0.5` 在归因路径中表示每侧肩宽为**实际核心宽度的一半**。
- 规则核心每个用户所设宽度前进。若最后一个规则核心与 `scan_high` 之间存在非整数尾段，
  追加一个宽度不变、右端锚定 `scan_high` 的完整核心；允许与前一个核心重叠，不缩窄
  尾段候选。
- `H_ref = 0` 且 `H_dut` 可逆时，纯幅度把对数幅度比视为负无穷，正权重处得到零补偿；
  相位在该点不可辨识，因此相位和幅相候选保守无效。`H_dut = 0` 时不猜测反演结果。
- 排名分数为候选补偿缩小“DUT 指标与参考指标差距”的程度；原始差距在
  `64 * eps * max(1, |reference|, |dut|)` 浮点尺度内为零时，不输出伪精确的
  “主要频段”。全频补偿结果作为模型闭环诊断，不对局部候选做硬门禁。
- 推荐在全部有效、正改善局部候选中，按原始分数锁定全局最佳频段。
  只有原始最佳为幅相时，才在**同一频段**内检查幅度和相位；单模式与联合改善之差在
  原始指标差距的 1%（与浮点容差取较大值）内时，选其中改善更大的单模式。该简化不
  允许切换到其他频段，也不参与“是否推荐”的模型门禁。
- 结果页显示频率×模式的影响曲线、推荐频段、补偿前/后/参考值与模型告警；点选其他
  候选时必须可重新查看对应波形或眼图。

## 5. 页面行为

- Vpp 模式显示原始波形补偿前/后及标量值，不显示眼图。
- 眼高/眼宽模式显示参考、补偿前、补偿后三幅眼图，三幅图共用显示范围。
- 点选候选列表中的频段时，仅更新补偿后图和当前频段摘要，补偿前和参考保持不变。
- 不可解析候选以 `NaN + valid_mask=False` 传给页面，曲线保留断点并显示数量诊断，不能
  用 0 冒充有效的零改善。
- 扫描在 Qt 后台线程运行；分配大型频谱前先估算候选数量、峰值内存和评估工作量，
  眼模式将 `symbol_count * M` 卷积与轨迹缓冲纳入内存上限。
  候选超过 2000 个或预计峰值内存超过 1.5 GB 时拒绝，目标样点数乘评估次数超过
  5000 万时提示长任务。
- 后台在文件加载之间、工作量估算后、工作区准备后、每次候选模式评估之间以及点选
  回放前后响应取消。已经进入的单次 FFT/IFFT 不强制杀死，而是在该数值步骤完成后
  丢弃过期结果；失败和取消均返回明确状态，不阻塞 Qt 主线程。
- 宽页面把指标、频段宽度、调制和 M 放在同一行，把纵向空间留给眼图；低于 640 px
  时参数自动回退两行。
- 窄窗口下页面允许纵向滚动，三幅眼图改为纵向堆叠，不用压缩字号或截断候选文字
  来勉强塞入视口。
- 现有五个页签、左右栏、工具栏和已批准视觉结构保持原样，本功能不开启全局 UI 重设计。

## 6. 代码与文件结构

- `src/response_lab/attribution.py`：眼指标、频段权重、扫描、排名与结果数据结构。
- `src/response_lab/virtual_eye_metrics.py`：折叠轨迹后的固定中心眼高与水平切片眼宽测量。
- `src/response_lab/attribution_metrics.py`：稳健 Vpp、极值诊断和跨采样率公共时长分块。
- `src/response_lab/influence_controller.py`：输入加载、工作量门禁、后台扫描和点选回放。
- `src/response_lab/influence_ui.py`：独立页签、文件选择、影响曲线、波形和眼图展示。
- `src/response_lab/ui.py`：把影响页接入主窗口，并隔离影响页与原补偿结果的版本状态。
- `tests/test_attribution.py`：独立手算/合成谕示、单一损伤扫描、无效输入与分辨率警告。
- `tests/test_virtual_eye_metrics.py`：本地眼图库数值反例、crossing 插值、分位数与批处理谕示。
- `tests/test_influence_controller.py`：请求、负载门禁、NRZ/PAM4 传递和展示数据角色映射。
- `tests/test_influence_ui.py` 与 `tests/test_influence_workflow.py`：轨迹协议、紧凑布局、真实文件扫描
  与候选回放。
- `tests/test_ui_workflow.py` 与 `tests/test_ui_visual_design.py`：主窗口交互和已批准界面回归。
- `docs/算法原理说明书.md` 和 `README.md`：加入用法、工程近似和失败边界。

## 8. 成功条件

1. 真实启动后存在`影响频段`页签，现有页签和视觉结构无回归。
2. 指标和调制下拉框只显示用户确认的简短标签；Vpp 与眼图输入状态正确切换。
3. 合成的单一幅度或相位异常能把主要影响定位到包含真值的最终候选频段，Hz/GHz、
   `M`、幅相模式或频带边界错误能被定向测试拒绝；相邻核心公共边界和锚定
   `scan_high` 的非整数尾段不存在漏扫缝。
4. NRZ 和 PAM4 的理想脉冲给出手算可检查的眼高/眼宽；三幅图均为
   `-1 UI ~ +1 UI`、每条 `2M+1` 点的真实卷积轨迹叠加，PAM4 以最小眼排名。
5. 两份不同长度和不同采样率原始数据可用于 Vpp 标量比较，不因逐点对齐假设失败。
6. 点选推荐或其他候选后，补偿后图与数值一致更新，参考/补偿前不变。
7. 运行时不因扫描卡死 Qt 主线程，失败、数据不足或模型不闭环时返回明确状态，不强行输出频段。
8. 聚焦测试、全量测试、Ruff、注释检查、`main.py --self-test`、GUI smoke test 与真实截图检查
   通过。

## 9. 边界

- 始终保持现有直接频域补偿方向 `H_ref / H_dut`，不修改已批准的补偿数学定义。
- 不添加 CDR、BER 外推、抖动分解、等化器或标准合规眼图。
- 不使用“根因频段”或“真实眼高/眼宽”等超出模型证据的结论。
- 不覆盖或夹带与本页签无关的全局视觉、README 或视觉测试改动。
