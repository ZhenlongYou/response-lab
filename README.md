# ResponseLab

ResponseLab 是一款频响分析与补偿桌面工具。它从两份拟合脉冲计算
`参考响应 / 待补偿响应`，在用户选择的频带内生成补偿响应，再通过
`FFT → 频域相乘 → IFFT` 把差异直接应用到 CSV 或 Keysight Infiniium 自描述 BIN
信号。界面采用深色三栏
工作台，包含拟合脉冲、频率响应、频响差异比较、频响补偿、输出预览和影响频段六个
页签。

## 三种独立操作

- **拟合脉冲比较**：只需选择“参考拟合脉冲”和“待补偿拟合脉冲”。该操作计算并显示
  脉冲、幅频、相频、差异和候选补偿响应，不读取待补偿信号，也不会产生可导出的补偿
  数据。
- **数据补偿**：在两份拟合脉冲之外，再选择 CSV 或 BIN 待补偿信号。该操作把候选补偿
  响应应用到信号，并启用“输出预览”和“导出补偿结果”。
- **影响频段**：选择 Vpp、眼高或眼宽中的一个指标，分别回放幅度、相位和幅相局部补偿，
  定位最能让 DUT 指标接近参考的大致频段。频段宽度支持 Hz、kHz、MHz、GHz，默认候选
  是 100 MHz 满权核心，两侧各接核心一半宽度的半余弦肩部；规则候选按所设宽度步进，
  不能整除的高端尾段用一个完整核心锚定到扫描上限，避免边界漏扫。Vpp 把同一理想
  周期码型分别与参考、DUT 拟合脉冲卷积，支持 `LFP 峰峰值` 与 `频域 RMS 误差`；
  眼高和眼宽使用拟合脉冲、NRZ/PAM4 和 M，并显示参考、补偿前、补偿后三幅 2 UI
  轨迹叠加眼图。Np 由脉冲样点数除以 M 自动计算。

影响频段功能要求两份拟合脉冲等长、等采样率。Vpp 使用同一个 `M` 把 UI 精确换算为
样点，并分别以两份脉冲中首次出现的 `argmax(abs(h))` 作为 pmax；用户设置峰前、峰后各
保留多少个完整 UI，窗口越过脉冲边界时直接拒绝，不静默截短或补零。界面项
`内置 PRBS13Q Gray（8191）` 是一个 8191-symbol 周期，归一化电平为
`{-1, -1/3, +1/3, +1}`；也可加载一列理想码型，并显式声明为 `0..3` 符号码或无量纲幅度系数，
工具不会猜测列含义。

这里 `Fs`、`Rs` 与 `M` 的关系固定为 `Rs=Fs/M`、`UI=M/Fs`。结果摘要同时显示
`Fs / Rs / M / UI`，让用户能发现填错 M 后产生的“数值合理、物理码率错误”模型。

窗口脉冲折叠到一个码型周期后与理想码型做圆周卷积，因此记录边界处也包含前后周期的
拖尾/ISI。LFP 是一个完整稳态周期上的精确 `max(y)-min(y)`，单位 V；频域方法直接对
候选与参考的**复频谱差**按 Parseval 计算去 DC 的 AC 误差，单位 Vrms，参考值定义为 0，
它不是“等效 Vpp”。扫描候选所用的 `H_ref/H_dut` 始终由两份**完整拟合脉冲**计算；
峰前/峰后窗口只控制指标模型包含多少拖尾，不会裁短补偿响应。建议逐步增加窗口，直到
排名和指标收敛，再把该设置用于结论。
由于周期模型把两条脉冲各自的 pmax 定义为零延迟，候选相位也会先减去两条 CSV 的
绝对峰值时刻差（包含 `t0` 与峰值索引差），再按用户选择决定是否去除剩余线性相位；
模型和补偿不会混用两套时间原点。

眼指标还要求`样点数`能被 `M` 整除，自动得到的 `Np ≥ 2`，且 `M ≥ 3`。若拟合脉冲或
Vpp 周期模型的物理分辨率不足用户所设频宽，工具会扩大实际窗宽并给出提示，不用零填充
频点冒充独立分辨率；此时余弦肩宽保持为实际满权核心宽度的一半。眼指标用固定符号冲激列与拟合脉冲卷积，再围绕冻结的主光标截取
`-1 UI ~ +1 UI`、每条 `2M+1` 点的轨迹；页面先按 DUT 补偿前的发送电平和中心幅度
分位从整段记录选取最多 600 个符号位置，参考/补偿前/补偿后严格复用这些位置，而不是
各画各的抽样或只取最前面的轨迹。主抽头按拟合脉冲最大
绝对峰值确定，不需要 Nb。轨迹生成后复用本地眼图库的轻量测量口径：默认眼高在固定
0 UI 取相邻轨道 1% 内侧经验边界之差；眼宽在相邻轨道中位数的 5%～95% 之间扫描
41 条固定电压水平切片，每条轨迹只保留左右最靠近眼中心的 crossing，线性插值并取最大
经验开口；1% 分位要求每侧至少 100 个 crossing，证据不足时报告不可测，不用 `0 UI`
冒充闭眼。这里的 1% 是
固定轨迹数据库的一侧分位数，不是 BER 外推。参考主光标只归一化
一次，DUT 和候选沿用同一幅值尺度与冻结原点，不能靠重新归一化或重新对齐获得虚假改善；
因此眼高是相对参考主光标的归一化有符号间隙，负值表示轨道重叠，不标成绝对电压 V。

影响页的纯幅度候选允许参考频响为零且 DUT 频响可逆，此时补偿幅度就是零；相位没有
定义，因此同一频点上的相位和幅相候选会保守标为不可解析。不可解析候选在影响曲线上
保留断点，不伪装成零改善。工具会在分配大型频谱前检查候选数量、眼图卷积缓冲和预计
峰值内存，并对长任务给出提示；分析在文件加载、工作区准备、候选评估和点选回放的阶段
边界响应取消，单次正在执行的 FFT/IFFT 或卷积不会被强制中断。LFP 每个候选需要一次
稳态 IFFT；频域 RMS 批量扫描直接在复频谱上计算，只有展示选中候选波形时才恢复时域。
Vpp 门禁按完整 `pattern_length × M` 周期计费：RMS 使用经独立 RSS 实测校准的
576 B/周期点，LFP 因额外周期 IFFT 使用 640 B/周期点，不会因候选频带较窄而低估；
估算结果还必须通过与加载器、主补偿相同的动态可用内存预算。眼图频段推荐还必须恢复
至少 1% 的基线差距；另外两个确定性符号种子会完整复扫全部候选频段和三种模式，只有
最佳模式保持一致且中心不漂移超过一个实际候选窗宽才保留推荐。

绘图区工具栏提供“放大 / 拖动 / 恢复”：放大模式用左键框选区域；拖动模式用左键平移，
滚轮仍可缩放；恢复会关闭自动量程并回到当前结果的确定性推荐范围。频率图的 y 轴只按
当前可见频带内的曲线设置，不会被 Nyquist 附近的无效低能量谱拉坏。

## 直接运行

首次使用先在终端完成一次项目环境初始化：

```bash
cd /Users/mac/PycharmProjects/RinysProject/codex_projects/frequency_response_compensator
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
python3 main.py
```

以后在 PyCharm 中直接运行项目根目录的 `main.py`，或执行 `python3 main.py` 即可。
`main.py` 会自动切换到本项目 `.venv`，不会修改系统 Python 或 Conda 环境；若尚未安装
依赖，也会直接显示上述初始化命令。

左下拟合脉冲轨迹会自动遵循 macOS“减少动态效果”辅助功能设置；也可用
`RESPONSELAB_REDUCE_MOTION=1 python3 main.py` 强制使用静止替代效果。

## 输入约定

### 拟合脉冲 CSV

- 自动识别 Keysight Infiniium `File Format, WaveformXYValues` 的格式版本 1/2：
  `Points`、`X Units, Second`、`Y Units, Volt` 和 `Data` 必须完整，v2 还会校验
  `Data` 后的 X/Y 精度声明。点数、单位、格式家族不一致会明确拒绝。
- 同时识别 Keysight 官方 Python 采集示例生成的
  `Time (s),<source> (V)` 两列表头。
- 继续兼容无表头 `time,value`；主界面把第 1 列解释为秒、第 2 列解释为伏特。
- 也接受表格软件保存的单字段记录：每行一个 CSV 字段，字段内写成
  `"时间, 幅度"` 或 `"时间 幅度"`。两项仍按时间、幅度解释；识别为该格式后，
  每个数据行都必须保持同一单字段、两数值结构，不能与普通两列行混用。
- 两份脉冲分别从时间列的中位时间间隔推导采样率，允许点数和采样率不同。
- 不要求手填采样率，也不会把 `Interpolation Factor` 当成采样率。FFT 分析要求均匀
  时间轴；Keysight XY 点不均匀时会提示在仪器导出中启用 `Linearly Interpolate`。

兼容格式示例（没有列名）：

```text
0.000000000,0.000012
0.000000001,0.014120
0.000000002,0.652300
```

### 待补偿信号 CSV

- 接受上述 Keysight `WaveformXYValues` v1/v2、官方 Python 两列表头，或无表头
  “时间（秒）+ 幅值（伏特）”两列格式；同样接受单字段内以逗号或空白分开的
  时间、幅值对。
- 采样率同样由第 1 列时间间隔推导，不需要手动输入。

当前不会把 `File Format, DatabaseCsv` 眼图命中矩阵、协议解码表、测量结果表或旧式
`Revision` 多源/分段 CSV 猜成时域波形。旧式 Keysight CSV 需要取得真实仪器样例后再建立
独立格式合同。ResponseLab 导出的补偿 CSV 仍是无表头 `time,value`，不冒充可回载仪器的
Keysight 自描述文件。

### 待补偿信号 BIN

- 只接受带 `AG` Cookie、版本 `10` 的 **Keysight Infiniium AG BIN**；工具从
  `X Increment` 自动得到 `Fs=1/XIncrement`，从 `X Origin` 恢复时间原点，并要求
  X 单位为 Second、Y 单位为 Volt。界面不再要求手动输入采样率，也没有“高级裸 BIN”
  的 dtype、字节序、偏移或通道布局猜测。
- 当前 GUI 入口要求文件只含一个 waveform；底层解析器可以显式按索引加载，但界面不会
  在多 waveform 文件中猜目标记录。可加载对象限于 Normal/Average 时域 waveform，且
  必须恰好有一个与 Points 一致的 little-endian normal `float32` buffer。
- 主“数据补偿”不再给 BIN 单设固定点数门限。CSV/BIN 归一化为 `TimeSeries` 后，
  `run_compensation` 在响应分析、CZT 和目标 FFT 前执行同一预检：小记录优先估算
  `E=3N-2` 整段精确路径；超过预算时自动改用有限边界重叠分块，并按完整 float32 输出、
  块 RFFT bins、脉冲 CZT 卷积长度与分析网格估算新增峰值工作区。
  本次预算取 8 GiB、系统当前可用内存的 50% 和“保留 512 MiB 系统余量”三者最小值；
  无法探测可用内存时回退为 768 MiB。加载阶段也使用同一动态预算：CSV 在
  `np.loadtxt` 前按文件字节、物理行数和实际选择列估算文本解析峰值；通用无表头 CSV
  用 `usecols` 忽略未选择列，Keysight 自描述 CSV 则完整校验每行恰好两列。BIN 在
  memmap/时间轴前按 `24 B/点 + 16 MiB` 估算。BIN 幅值保持原生 float32；100 万点
  两次独立进程实测加载新增峰值约 19.9–20.8 MiB（macOS arm64，具体值随运行库变化）。
  只读 memmap 也不等于无限内存承诺。
- 未知 AG 版本、随机裸样本流、Peak Detect/复合 buffer、非秒 X 轴、非伏特 Y 轴以及
  其他 Keysight BIN 家族会明确拒绝。文件扩展名是 `.bin` 不等于格式受支持。
- 导出的 BIN 是单 waveform、Normal、little-endian `float32` 的 AG10 文件，保留等间隔
  时间轴的采样率和起始时间，可由本工具重新导入；它不是任意 Keysight/第三方 BIN 的
  无损往返编辑器。

CSV 格式依据见 Keysight 官方的
[Waveform XY CSV 说明与 v1/v2 示例](https://helpfiles.keysight.com/csg/d9300a/Help/Infiniium-UG/Content/Topics/Files/waveform_xy_files.htm)、
[CSV 表头开关说明](https://helpfiles.keysight.com/csg/d9300a/Help/Infiniium-PG/Content/Topics/Commands/DISK/WAVeform_HEADer.htm)
与[官方 Python 浮点波形采集示例](https://helpfiles.keysight.com/csg/d9300a/Help/Infiniium-PG/Content/Topics/Python/Scripts/waveform-data-float-format.htm)。

BIN 格式依据见 Keysight 官方的
[Waveform BIN 文件说明](https://helpfiles.keysight.com/csg/d9300a/Help/Infiniium-UG/Content/Topics/Files/waveform_BIN_files.htm)、
[BIN File Format 字段表](https://helpfiles.keysight.com/csg/d9300a/Help/Infiniium-UG/Content/Topics/Files/BIN_File_Format.htm)
与[官方 Python 转 CSV 示例](https://helpfiles.keysight.com/csg/d9300a/Help/examples/XR8/binary-to-csv.py)。

### Vpp 理想码型文件

- 使用 CSV 或 TXT，一行一个数值且只能有一列；空文件、NaN/Inf 和多列输入会被拒绝。
- `Gray 符号码 0–3` 只接受整数 `0、1、2、3`，并映射到归一化 PAM4 电平；
  `无量纲幅度系数`保留文件的数值尺度与偏置，但至少要包含两个不同电平。码型系数
  没有电压单位，拟合脉冲承担每单位符号响应的电压量纲，因此卷积输出和 LFP 仍为 V。
- 文件在 `np.loadtxt` 前先检查 32 MiB 硬上限与动态内存预算，并把初始大小内容冻结为
  有界快照；并发追加不能扩大解析输入。有效 symbol 行数还会先进入周期 FFT 内存门禁，
  超限时要求提供“一列单周期 symbol，而不是采集波形”。该入口不能绕过大数据门禁。
- 文件内容代表一个完整周期；周期样点数为 `码型行数 × M`，参考、DUT 与所有候选共用
  同一周期。该文件描述理想激励，不是示波器采集波形。

## 补偿方向和相位策略

补偿方向固定为：

```text
C_ideal(f) = H_reference(f) / H_dut(f)
```

默认勾选“根据拟合脉冲自动设置补偿频带”：工具在两份脉冲各自峰值归一化后，寻找两者都
不低于 -20 dB 的最长连续谱宽候选，并在两端留出裕量。它是幅度启发式，不是噪声底或
相位可信度估计；输入应已去除直流基线，用户仍需检查拟合带内相位质量。该设置随输入
变化，不会把公共 Nyquist 当成可信带宽。线性相位拟合频带在首次分析时自动给出初值并固定；
无论用户是否继续手动调整，后续自动补偿频带都不会再改写该范围。

模式支持“仅幅频”“仅相频”“幅频 + 相频”。用户选择补偿频带；默认在每侧使用补偿
带宽 10% 的 raised-cosine，从单位响应平滑进入带内响应，避免硬切换造成过强时域振铃。
在含相位的模式中，工具会在用户指定的“相位拟合频带”内拟合相位差线性项
`slope·f`，并始终报告 `estimated_relative_delay_s=slope/(2π)`。正时延表示 DUT
比参考更晚。默认勾选“去除线性相位（保持目标时间位置）”，此时实际
补偿相位为 `Δφ-slope·f`；关闭时仍拟合并报告时延，但补偿相位保留完整
`Δφ`，因而会尝试对齐相对时间。常数相位和非线性相位差在两种设置下都保留。
“仅幅频”不应用相位补偿，但仍显示相位差供诊断。

去斜采用按频谱置信度加权的最小二乘斜率。若频谱零点把可信频带分成多个相位岛，每个
相位岛使用独立截距，只汇总岛内相位随频率的变化量；这样整数个 `2π` 的展开偏移不会
被误判成线性斜率。零权重频点不参与拟合，不会被强制抬成同权。界面相位图与实际补偿
共用同一斜率拟合实现；实际只扣除 `slope·f`，不会伪造一个跨相位岛的全局截距。

打开去斜时，“频率响应”页分别扣除两份脉冲各自的线性相位，再给每个连续
相位岛统一平移整数个 `2π`；关闭时显示未去斜相位。“频响差异比较”页仅在打开
去斜时同时显示去斜前后曲线，关闭时明确标出“未去斜，实际补偿”。蓝色阴影表示
分析或补偿频带，橙色虚线标记线性相位拟合频带，图例会同时声明实际是否去斜。

原始幅相差异完整保留在诊断曲线中；实际应用默认把最大补偿增益限制为 20 dB，并在
发生限制时显示原始所需峰值与实际上限。界面允许修改上限，或以专家选项显式关闭限制；
运行结果按目标信号的实际 DFT bins 更新峰值告警，并以目标 Nyquist 判断边缘是否需要
过渡；相位肩部会连续展开 ±π 分支。这些设置会进入 JSON 参数记录。所选频带外严格
使用单位响应。若所选频带包含待补偿
响应为零、无法计算响应比的频点，工具仍会要求缩小或移动补偿频带，增益限制不会把
数学零点伪装成可逆响应。

## 导出

“导出补偿结果”会同时生成：

- `<原名>_compensated.csv` 或 `.bin`：等长补偿信号；CSV 仍然无表头，BIN 为包含
  `Fs` 与时间原点的单 waveform Keysight Infiniium AG10（Normal、little-endian
  `float32`、Second/Volt）。
- `<原名>_compensated_response.csv`：绘图所用的频率响应与差异诊断表。两路幅度均按
  `20·log10(|dt·RFFT(h)|)` 保留各自输入幅值标度，再插值到共同分析网格；这里不做
  峰值归一化。自动推荐 -20 dB 频带时才会在内部把两路频谱分别按各自峰值归一化。
- `<输出文件>.response-lab.json`：`response-lab-manifest/v4`，记录输入哈希、有效参数、
  去斜斜率、带符号相对时延、原始频响 dB 定义与标度、频域应用信息、
  输出统计和输出文件哈希。

响应 CSV 中：`phase_difference_deg` 是分岛展开的原始相位差；
`fitted_linear_phase_trend_deg` 是 `slope·f` 且不包含各岛截距；
`phase_after_optional_detrend_deg` 是依开关得到的实际带内相位源；
`correction_phase_deg` 是 `angle()` 返回的包裹相位。

小记录自动做完整首尾镜像延拓；大记录在整段路径超过安全预算时，改用“真实相邻样本
重叠 + 只在完整记录两端有限镜像”的分块路径。两者都按目标 FFT 的实际频点通过 CZT
计算两份拟合脉冲的有限记录频响，再构造 `H_reference/H_dut` 后相乘。分块上下文由
补偿冲激响应的 float32 量化与截尾联合相对 L1 界决定，已计入预算的尾部会实际置零，
不能满足时失败关闭。显示分析网格只用于绘图和诊断，
不作为实际应用响应的插值源，
因此落在显示网格两点之间、却落在目标 DFT 频点上的窄陷波不会被抹平。输出与输入保持
相同的点数、时间轴和通道数。

接近谱零点的频点会用直接多项式求值复核，并按与记录长度、系数 L1 范数有关的 Horner
舍入误差界判断是否仍可解析；低于误差界的 DUT 响应会拒绝补偿，可解析的有限小响应仍
按用户设置原样应用。若目标记录过短、补偿带内没有实际 DFT 频点，或目标 Nyquist 需要
实值 RFFT 端点无法表示的复相位，工具也会明确拒绝，而不是静默返回未补偿或失相结果。

三份源文件在导出前后都会与分析时的大小和 SHA-256 快照核对；若文件被外部修改，
必须重新分析。三个输出先完整写入同一文件系统的暂存目录，再作为一个可回滚批次提交，
避免普通写入异常留下相互不匹配的半套结果。
